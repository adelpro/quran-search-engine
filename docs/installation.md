# Installation Guide

The library is designed with `pnpm` workspaces for optimal caching, performance, and mono-repo execution. It can be utilized via `npm` or `yarn`.

## Default Installation

```bash
pnpm install quran-search-engine
```

### Alternatives

<details> 
<summary>NPM / Yarn</summary>
<br>

```bash
npm install quran-search-engine
# or
yarn add quran-search-engine
```

</details>

## Requirements

The library leverages async contexts natively `(Node 18+, ESM, browsers)` and targets modern ECMAScript. Ensure you're compiling TypeScript code paths for compatible resolution.

If running full examples, a global `pnpm` installation is recommended:

```bash
npm install -g pnpm
```
